# Support

Use the public issue tracker for reproducible bugs and feature requests:

- Search existing issues first.
- Include the extension version, Chrome version, operating system, and clear reproduction steps.
- Add screenshots only after checking that they contain no addresses, account details, reservation information, or other personal data.

For installation problems, confirm that you extracted the release ZIP and selected the folder containing `manifest.json` with Chrome's **Load unpacked** button.

Do not use a public issue to report a security vulnerability. Follow [SECURITY.md](SECURITY.md) instead.
